# Financial Model Evaluation

A five-year cash-flow model built with synthetic data. It runs base, downside, and upside cases. Assumptions, calculations, checks, and limits are included in the output.

## Included

- Revenue, margin, investment, growth, and discount-rate assumptions
- Base, downside, and upside cases
- Input validation and scenario-order checks
- JSON output that can be reviewed without opening the code

## Run

```bash
python3 model.py
```

This is a code sample. It is not employer or client work. It is not investment advice. The model does not include terminal value, tax, financing, or a balance sheet.
